# Agenda de contactos

Proyecto de práctica de Git

## Cómo usar

Este repositorio es una agenda personal que contiene:

- `README.md`: Este archivo con descripciones.
- `contactos.txt`: lista de contactos con su teléfono y correo.
- `tareas.txt`: lista de tareas pendientes.
- `compras.txt`: lista de compras.
- `.gitignore`: Todo lo que el repositorio va a ignorar.
